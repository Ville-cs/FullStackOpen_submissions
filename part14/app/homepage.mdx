# This is a modern Next.js full-stack blog application

## The app supports user registration and authentication, adding personal blogs, inserting other users blogs to one's own reading list etc.

To start using the app, do this:

- On the top of the page click register.
- Insert your information and click the register button
- On the login page input the details you just created
- Start using the app! Create new blogs, view blogs and other users. Also,
  manage your reading list on your personal "me" page
